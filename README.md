# Ayşe Nane Gayrimenkul & Yatırım Danışmanlığı

Antalya ve Akdeniz bölgesinde faaliyet gösteren Gayrimenkul Danışmanı **Ayşe Nane** için özel olarak tasarlanmış, ultra lüks, modern, mobil uyumlu ve yüksek dönüşüm odaklı kurumsal web sitesi.

---

## 🌟 Öne Çıkan Özellikler

1. **Ultra Lüks & Modern Akdeniz Tasarımı:**
   - Gece mavisi, şampanya altını ve fildişi renk paleti.
   - Cam efekti (glassmorphism) ve pürüzsüz mikro-etkileşimler.
   - Ayşe Hanım'ın profil fotoğrafı ve MYK Seviye 5 lisans akreditasyonu.

2. **Gelişmiş Portföy Vitrini & Filtreleme:**
   - Lüks villalar, sahil rezidansları, yatırımlık arsalar ve ticari gayrimenkuller.
   - Bölge bazlı hızlı filtreleme (Döşemealtı, Lara, Konyaaltı, Kaş-Kalkan, Belek, Alanya).
   - Kapsamlı ilan detay modalı, fotoğraf galerisi ve özellik dökümü.

3. **Müşteri Edinme (Lead Generation) Modülleri:**
   - **Ücretsiz Mülk Değerleme Formu:** Evini satmak isteyen mülk sahipleri için özel emsal talep formu (konfeti kutlaması ve KVKK uyumlu).
   - **Antalya Yatırım & Amortisman Hesaplayıcı:** Dinamik kira getirisi, amortisman süresi ve 5 yıllık bileşik varlık projeksiyonu simülatörü.
   - **Danışmanlık & Randevu Modülü:** Ofiste kahve eşliğinde, mülk başında veya online video görüşme randevu planlayıcısı.

4. **Sosyal Medya & WhatsApp Entegrasyonu:**
   - **Instagram Vitrini:** Doğrudan `@aysenane.gayrimenkul` hesabı ve son paylaşımlar.
   - **Akıllı WhatsApp Butonları:** Her ilan kartında mülke özel hazırlanmış hazır mesaj şablonu.
   - **Sabit WhatsApp Canlı Danışma Widget'ı:** Çevrim içi durum göstergeli hızlı mesajlaşma balonu.

5. **Antalya Bölge Rehberi:**
   - Döşemealtı, Lara, Konyaaltı, Kaş/Kalkan, Belek ve Alanya mikromarket analizleri, değer artış trendleri ve yaşam tarzı profilleri.

---

## 🛠️ Teknoloji Yığını

- **Framework:** Next.js 15 (App Router)
- **UI Kütüphanesi:** React 19
- **Stil & Tasarım:** Tailwind CSS
- **İkonlar:** Lucide React
- **Mikro Etkileşim:** Canvas Confetti
- **Dil:** TypeScript

---

## 🚀 Yerel Geliştirme (Local Development)

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açarak inceleyebilirsiniz.
